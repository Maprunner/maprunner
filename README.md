# Maprunner

Built with [11ty](https://www.11ty.dev/) and [Tailwind CSS](https://tailwindcss.com/docs).

## Running locally

Things are now managed with pnpm. To run locally:

```
pn dev
```

This starts a server. The site can be accessed at [Maprunner](http://localhost:8080/)

## Deploying

```
pn build
```

Sync dist to [www.maprunner.co.uk](www.maprunner.co.uk)
